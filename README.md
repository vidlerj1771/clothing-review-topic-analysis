Clothing Review Topic Analysis

Overview

This project uses text embeddings in Python to analyse customer reviews from a women's clothing e-commerce dataset. The aim is to uncover underlying topics and themes within the reviews while also gaining insights into customer sentiment and opinions.
The analysis demonstrates how AI and natural language processing techniques can be used to understand large amounts of unstructured customer feedback.

Features
- Analyses customer reviews from an e-commerce dataset
- Uses text embeddings to represent review content
- Identifies underlying themes and topics within reviews
- Helps uncover patterns in customer feedback
- Provides insights that could support improvements to products and customer service

Technologies Used
- Python
- Text Embeddings
- Natural Language Processing
- Pandas
- Jupyter Notebook

How It Works

The project processes customer reviews and converts the text into numerical representations using text embeddings.
These embeddings allow reviews with similar meanings or themes to be identified and analysed together. The results can then be used to uncover common topics, understand customer sentiment and identify patterns within the feedback
