Clothing Review Topic Analysis

Overview

This project uses AI-powered text embeddings to analyse customer reviews from a women's clothing e-commerce dataset. The aim is to uncover underlying topics and themes within the reviews while also gaining insights into customer sentiment and opinions.
The analysis demonstrates how AI and natural language processing techniques can be used to understand large amounts of unstructured customer feedback.

Technologies Used
- Python
- Text Embeddings
- Natural Language Processing
- Pandas
- Jupyter Notebook

How It Works

The project takes customer clothing reviews as text data and uses text embeddings to represent the meaning of each review numerically. These embeddings can then be compared to identify reviews with similar themes.
The analysis helps uncover patterns in customer feedback, such as recurring opinions about products, fit, quality and other aspects of the shopping experience.

How to Run / Test
1. Clone or download this repository.
2. Open the Jupyter Notebook (.ipynb file).
3. Make sure the required Python libraries are installed.
4. Run the notebook cells from beginning to end.
5. Review the generated analysis and results.

The notebook contains the code and steps required to reproduce the analysis.
