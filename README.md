Clothing Review Topic Analysis

Overview

This project uses AI-powered text embeddings to analyse customer reviews from a women's clothing e-commerce dataset. The aim is to identify underlying topics and themes within customer feedback and explore patterns in customer opinions.

The project demonstrates how natural language processing and text embeddings can be used to analyse large volumes of unstructured text and identify similarities between customer reviews.

Technologies Used
- Python
- Text Embeddings
- Natural Language Processing (NLP)
- Pandas
- Jupyter Notebook

What I Built

I developed a Python-based analysis that processes customer reviews and converts the text into numerical representations using text embeddings. These embeddings allow reviews with similar meanings or themes to be identified and compared.

The analysis explores recurring themes within the reviews, including:

- Product quality
- Clothing fit
- Customer opinions
- Product characteristics
- Common themes in customer feedback

The project demonstrates a practical application of AI and NLP for extracting insights from unstructured customer data.

How It Works
1. Customer reviews are loaded and prepared for analysis.
2. Text embeddings are generated to represent the meaning of each review numerically.
3. Reviews are compared based on their embeddings to identify similarities.
4. The results are analysed to uncover recurring topics and patterns.
5. The findings are visualised and interpreted to provide insights into customer feedback.

How to Run / Test
1. Clone or download this repository.
2. Open the Jupyter Notebook (.ipynb file).
3. Install the required Python libraries.
4. Run the notebook cells from beginning to end.
5. Review the generated analysis, visualisations and results.

The notebook contains the code and steps required to reproduce the analysis.

Project Outcome

This project demonstrates how AI-powered embeddings and NLP techniques can be applied to real-world customer feedback to identify meaningful patterns within unstructured text.
